# Flight Plan

A mobile-friendly javelin training planner with a 48-week season outlook, daily sessions, exercise weight tracking, notes, and offline support.

## GitHub Pages

1. Create a GitHub repository named `javelin-training-planner`.
2. Upload every file in this folder to the repository root.
3. Open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Open the Pages URL shown by GitHub on your phone and use **Add to Home Screen**.

The app stores weights, notes, and completion status in the browser on each device. Those values do not sync between devices yet.
